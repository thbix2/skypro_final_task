Git

  • git init — Создать новый локальный Git-репозиторий в текущей папке.
  • git clone <URL> — Скопировать удалённый репозиторий на компьютер.
  • git status — Показать состояние рабочей директории и подготовленных изменений.
  • git add <имя_файла> — Добавить указанный файл в область подготовленных изменений. Команда git add . добавляет все изменения из текущей папки.
  • git commit -m "сообщение" — Создать коммит с подготовленными изменениями и коротким описанием.
  • git push — Отправить локальные коммиты в удалённый репозиторий.
  • git pull — Получить изменения из удалённого репозитория и объединить их с текущей веткой.
  • git log — Показать историю коммитов.
  • git diff — Показать различия между изменёнными файлами и последней зафиксированной версией.
